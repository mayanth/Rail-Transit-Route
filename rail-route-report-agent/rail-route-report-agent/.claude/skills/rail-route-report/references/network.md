# โครงข่ายรถไฟฟ้า (กรุงเทพฯ และปริมณฑล) — ใช้ร่างเส้นทางเท่านั้น

> ⚠️ ไฟล์นี้เป็นข้อมูลโครงสร้างที่เปลี่ยนช้า ใช้ช่วย "ร่าง" เส้นทาง
> **ต้องยืนยันสถานะสถานี จำนวนสถานี และค่าโดยสารจากแหล่งออนไลน์ทุกครั้ง** (ดู `sources.md`)
> หากพบว่าข้อมูลในไฟล์นี้ไม่ตรงกับแหล่งทางการ ให้ยึดแหล่งทางการ และบันทึกใน `memory/MEMORY.md` → Lessons Learned

## สายรถไฟฟ้าและผู้ให้บริการ
| สาย | ผู้ให้บริการ | ปลายสาย (ใช้บอกทิศทาง) | ระบบตั๋ว |
|---|---|---|---|
| BTS สายสุขุมวิท (เขียวอ่อน) | BTSC | คูคต ↔ เคหะฯ | BTS |
| BTS สายสีลม (เขียวเข้ม) | BTSC | สนามกีฬาแห่งชาติ ↔ บางหว้า | BTS |
| BTS สายสีทอง | BTSC | กรุงธนบุรี ↔ คลองสาน | BTS |
| MRT สายสีน้ำเงิน | BEM | วงรอบ (ท่าพระ/หลักสอง) — ตรวจป้ายทิศทางปัจจุบัน | MRT |
| MRT สายสีม่วง | BEM | คลองบางไผ่ ↔ เตาปูน | MRT |
| MRT สายสีเหลือง | EBM (กลุ่ม BTS) | ลาดพร้าว ↔ สำโรง | แยก (ตรวจ) |
| MRT สายสีชมพู | NBM (กลุ่ม BTS) | ศูนย์ราชการนนทบุรี ↔ มีนบุรี | แยก (ตรวจ) |
| Airport Rail Link (ARL) | ผู้ให้บริการปัจจุบัน (ตรวจ) | พญาไท ↔ สุวรรณภูมิ | ARL |
| SRT สายสีแดงเข้ม | รฟฟท. | กรุงเทพอภิวัฒน์ ↔ รังสิต | SRT Red |
| SRT สายสีแดงอ่อน | รฟฟท. | กรุงเทพอภิวัฒน์ ↔ ตลิ่งชัน | SRT Red |

## จุดเปลี่ยนสายหลัก
| สถานี A | สถานี B | ประเภท |
|---|---|---|
| BTS สยาม (สุขุมวิท) | BTS สยาม (สีลม) | ในระบบ (ชานชาลาร่วม) |
| BTS อโศก | MRT สุขุมวิท | ข้ามระบบ — ทางเดินเชื่อม |
| BTS หมอชิต | MRT สวนจตุจักร | ข้ามระบบ — ทางเดินเชื่อม |
| BTS ห้าแยกลาดพร้าว | MRT พหลโยธิน | ข้ามระบบ — ทางเดินเชื่อม |
| BTS ศาลาแดง | MRT สีลม | ข้ามระบบ — ทางเดินเชื่อม |
| BTS บางหว้า | MRT บางหว้า | ข้ามระบบ |
| BTS พญาไท | ARL พญาไท | ข้ามระบบ |
| BTS กรุงธนบุรี | BTS สายสีทอง กรุงธนบุรี | ตรวจว่าต้องแตะบัตรใหม่หรือไม่ |
| BTS สำโรง | MRT สายสีเหลือง สำโรง | ข้ามระบบ |
| BTS วัดพระศรีมหาธาตุ | MRT สายสีชมพู วัดพระศรีมหาธาตุ | ข้ามระบบ |
| MRT เพชรบุรี | ARL มักกะสัน | ข้ามระบบ — ทางเดินเชื่อม |
| MRT เตาปูน (น้ำเงิน) | MRT เตาปูน (ม่วง) | ในสถานีเดียวกัน (ตรวจเงื่อนไขค่าแรกเข้า) |
| MRT ลาดพร้าว (น้ำเงิน) | MRT ลาดพร้าว (เหลือง) | ข้ามระบบ |
| MRT บางซื่อ | SRT กรุงเทพอภิวัฒน์ | ข้ามระบบ — ทางเดินเชื่อม |
| ARL หัวหมาก | MRT สายสีเหลือง หัวหมาก | ข้ามระบบ |
| SRT หลักสี่ | MRT สายสีชมพู หลักสี่ | ข้ามระบบ |
| MRT ศูนย์ราชการนนทบุรี (ชมพู) | MRT ศูนย์ราชการนนทบุรี (ม่วง) | ข้ามระบบ |

## ชื่อสถานีที่ต้องถามกลับ (กำกวม)
| ผู้ใช้พิมพ์ | ตัวเลือกที่เป็นไปได้ |
|---|---|
| บางซื่อ | MRT บางซื่อ · SRT กรุงเทพอภิวัฒน์ (สถานีกลางบางซื่อเดิม) |
| ลาดพร้าว | MRT ลาดพร้าว (น้ำเงิน) · MRT ลาดพร้าว (เหลือง) · BTS ห้าแยกลาดพร้าว |
| จตุจักร / หมอชิต | BTS หมอชิต · MRT สวนจตุจักร · MRT กำแพงเพชร (ตลาดนัดจตุจักร) |
| สีลม | BTS ศาลาแดง · MRT สีลม · "สายสีลม" ทั้งสาย |
| สุขุมวิท | MRT สุขุมวิท · "สายสุขุมวิท" ทั้งสาย |
| บางหว้า / สำโรง / พญาไท / หัวหมาก / เตาปูน / หลักสี่ / ศูนย์ราชการนนทบุรี | มีหลายสายที่ชื่อเดียวกัน — ถามว่าสายไหน หรือแจ้งว่าเป็นจุดเปลี่ยนสาย |
| สนามบิน | สุวรรณภูมิ (ARL) · ดอนเมือง (SRT สายสีแดงเข้ม) |
| ชื่อห้าง/สถานที่ | เสนอสถานีใกล้สุด 1–3 แห่งให้ผู้ใช้เลือก |
