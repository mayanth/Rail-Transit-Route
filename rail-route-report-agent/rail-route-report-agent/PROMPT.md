# PROMPT — สั่ง Rail Route Report Agent

## Prompt หลัก (สร้าง / อัปเดตรายงาน)
```
จัดทำรายงาน PDF "ระบบค้นหาเส้นทางเดินทางด้วยรถไฟฟ้า" ฉบับวันที่ {YYYY-MM-DD}
ตาม CLAUDE.md, skill rail-route-report และ memory/MEMORY.md

ต้องมี:
1. รายชื่อผู้ให้บริการรถไฟฟ้าทุกสายที่เปิดให้บริการในประเทศไทย พร้อมลิงก์เว็บไซต์และลิงก์ค่าโดยสารที่กดได้
2. อัตราค่าโดยสารตามเว็บไซต์ รฟม. (ตัวเลขถ้าอ่านได้ / ลิงก์ทางการถ้าอ่านไม่ได้)
3. หน่วยงานรัฐที่เกี่ยวข้อง และสายที่ยังไม่เปิดให้บริการ
4. ตัวอย่างการค้นหาเส้นทางที่ครบ Requirements 1–10:
   รับต้นทาง/ปลายทาง · เส้นทางที่ใช้ได้ · สายที่ใช้ · สถานีเปลี่ยนสาย · จำนวนครั้งเปลี่ยน ·
   ต้นทาง/ปลายทางชัดเจน · ค่าโดยสารปัจจุบัน · หลายเส้นทางให้แนะนำเร็วสุด/เปลี่ยนน้อยสุด ·
   แจ้งการเดินเชื่อม/เปลี่ยนระบบ · อ้างอิงข้อมูลปัจจุบัน
5. สรุปผลภาพรวม และแหล่งที่มาท้ายเอกสาร พร้อมเลขหน้า

เงื่อนไข: ห้ามเดาข้อมูล · ทุกข้อมูลมีแหล่งที่มาและเวลาที่ตรวจ · แยกสถานะ ยืนยันแล้ว /
ไม่สามารถยืนยันได้ / ไม่พบข้อมูล / ไม่มีบริการ · ใช้สีตาม Template excel ·
ตั้งชื่อไฟล์ rail_route_{YYYY-MM-DD}.pdf
```

## Prompt ย่อย (แก้รายงาน) — ตัวอย่างที่ใช้จริง
| งาน | Prompt |
|---|---|
| ใส่ลิงก์ | `ใส่ลิ้งนี้ ที่ช่อง ลิงก์ ที่ค่าโดยสาร: ของ {สาย} {URL} ใน pdf` |
| ใส่ข้อมูลจากเว็บ | `จงใส่อัตราค่าโดยสารจากเว็บไซต์นี้ {URL}` |
| ลบส่วน | `ลบส่วนที่ {n} {ชื่อส่วน} จากไฟล์ pdf` |
| แก้หัวคอลัมน์ | `จงลบคำว่า (กดได้) จาก Column ลิงก์` |
| เปลี่ยนสถานะ | `เปลี่ยนสถานะ ไม่สามารถยืนยันได้ เป็น สถานะ ยืนยันแล้ว ที่ช่อง สถานะลิงก์` |
| เพิ่มสรุป | `เพิ่มส่วนสรุปผลของข้อมูลทั้ง pdf ในไฟล์` |
| เปลี่ยนชื่อไฟล์ | `แก้ชื่อไฟล์เป็น rail_route_{YYYY-MM-DD}.pdf` |
| ตรวจ Requirements | `จงใส่ข้อมูลใน pdf ให้ครบตาม Requirement ในภาพ` |
| อัปเดต Agent | `update CLAUDE.md and skill.md and memory.md` |

## ผลลัพธ์ที่คาดหวัง
- ไฟล์ `rail_route_{YYYY-MM-DD}.pdf` ตามโครง `references/report-spec.md`
- ข้อความตอบกลับสั้น: เปลี่ยนอะไร · ข้อจำกัดที่ยังเหลือ · ชื่อไฟล์
- `memory/MEMORY.md` อัปเดตแล้ว
